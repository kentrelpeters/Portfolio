## Featured coursework projects

### [My To-Do List](https://github.com/kentrelpeters/todo-app)

A Flask web app that lets users add tasks and mark them complete or incomplete.

- **Technologies:** Python, Flask, HTML, CSS.
- **Concepts demonstrated:** Routes, form submissions, template rendering, and updating task state.
- **Current limitation:** Tasks are stored in memory and disappear when the server restarts. There are no separate user accounts.
- **Try it:** Follow the project's [setup and usage instructions](https://github.com/kentrelpeters/todo-app#run-locally).

### [TechFlow Solutions Website](https://github.com/kentrelpeters/Collab-deployment)

An educational sample company website with home, about, team, and contact sections.

- **Technologies:** HTML, CSS, JavaScript, and a GitHub Actions deployment workflow.
- **Concepts demonstrated:** Page structure, styling, scrolling navigation, and client-side form handling.
- **Current limitation:** The contact form displays an alert; it does not send or store messages. Company details and team profiles are sample content.
- **Try it:** Follow the project's [local setup instructions](https://github.com/kentrelpeters/Collab-deployment#run-locally).
